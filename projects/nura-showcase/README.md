# NURA EPC Showcase — мастер-шаблон web-презентации

Ночной 3D-мир (Three.js r128 + bloom) с облётом по скроллу: ПС → ОРУ → ВЛ → СЭС → BESS → общий план,
затем блоки-шаблоны: «Суть предложения» (КПЭ), однолинейная схема с перетоком мощности,
интерактивная матрица форматов (Поставка / Поставка+вторичка / СМР+ПНР / EPC / EPC+F),
диаграмма Ганта, «Следующий шаг».

- Палитры: «Рассвет» (по умолчанию), «Ночь», «День» — переключатель в верхней панели; цвета 3D-сцены в объекте `SKINS`, цвета страницы в CSS-токенах `:root[data-skin]`.
- Выноски 3D сами обходят карточки, верхнюю панель, края экрана и друг друга.
- Навигация на встрече: → / PageDown / пробел — следующий раздел, ← / PageUp — назад (подходит кликер).
- Библиотеки — из `vendor/` (симлинк на `assets/vendor`); при публикации передаются через `files`.
- Разделы с пометкой «Шаблон · демо-данные» — пример заполнения (ПС 220/10 кВ, 2×125 МВА, 14 мес., EPC+F),
  заменять данными реального проекта.
- Под проект: тексты глав (`.chapter`), КПЭ (`.kpis`), этапы схемы (`.step` + группы `g1..g4` в SVG),
  массивы `FMT`, `G` (график) и `CO` (выноски 3D) в скрипте; ракурсы камеры — массив `K`.
