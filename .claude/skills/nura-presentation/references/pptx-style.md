# Правила PowerPoint / PDF-версий

PPTX-версия нужна для госорганов, официальной переписки, печати и показа
с проектора. Это не «урезанная» web-версия, а самостоятельный документ
в том же фирменном стиле и по тому же утверждённому сценарию.

## Технология

- Создание — через скилл `anthropic-skills:pptx` (строго по его процессу,
  включая валидацию файла).
- Формат 16:9. Одна презентация — один мастер-стиль, без смешения шаблонов.
- Если существует web-версия с 3D: экспортируй из неё ключевые ракурсы
  как изображения (кадры сцены в высоком разрешении) и используй на слайдах
  вместо «живого» 3D. Разрез/взрыв-схему давай серией из 2–3 статичных
  кадров.

## Стиль слайдов

- Палитра и шрифты — из `design-system.md`. Для печати и проектора
  предпочтительна светлая тема (`--nura-paper` фон, тёмный текст);
  тёмная допустима для показа с экрана. Внутри одной презентации тему
  не смешивать (исключение: титул и финал могут быть тёмными «обложками»).
- Минимальный размер текста на слайде — 14 pt, основной — 16–18 pt,
  заголовки — 28–40 pt. С проектора мелкий текст не читается.
- Один слайд — одна мысль; максимум ~5 пунктов списка по одной строке.
  Длинные обоснования — в раздаточный материал, не на слайд.
- Таблицы (цены, объёмы, график): строгие линии 0.5–1 pt, числа
  выравнивать по правому краю, единицы измерения в шапке столбца.
  Итоговые строки выделять жирным, не цветом.
- Колонтитул: «NURA GROUP» слева, номер слайда справа; на титуле
  и финале колонтитула нет. При конфиденциальных ценах — пометка
  о конфиденциальности на титуле и в колонтитуле.
- Диаграммы — по правилам `dataviz`: без 3D-эффектов Office, без теней,
  подписи данных прямо у элементов вместо легенды, где возможно.

## Типовой состав (адаптировать по сценарию)

1. Титул: объект, заказчик, формат участия, дата.
2. Резюме предложения: 3–5 КПЭ крупно.
3. Объект: рендер/компоновка с подписями узлов.
4. Технические решения: однолинейная схема, основное оборудование.
5. Состав работ/поставки по формату (поставка / СМР+ПНР / EPC / EPC+F).
6. Референсы и лицензии NURA.
7. График реализации: горизонтальная шкала с вехами.
8. Коммерческие условия (если уместно для аудитории).
9. Финал: следующий шаг, контакты.

## Контроль качества PPTX

1. Валидация файла инструментами скилла pptx (обязательно).
2. Визуальный проход по каждому слайду: переносы слов, «висячие» строки,
   выравнивание блоков, не съехали ли подписи.
3. Проверка цифр против исходных данных.
4. Язык: единый по всему файлу, грамотный, официальный.
5. PDF-экспорт (если просили PDF): шрифты встроены, ничего не съехало.
