# NURA Presentation System

Система создания профессиональных презентаций NURA GROUP / NURA EPC:
высоковольтные подстанции 10–500 кВ, ЛЭП, солнечные электростанции, BESS.

## Структура

- `.claude/skills/nura-presentation/` — скилл-система создания презентаций:
  - `SKILL.md` — процесс: бриф → анализ и сценарий → производство →
    контроль качества → сдача;
  - `references/design-system.md` — фирменный стиль (палитра, типографика,
    композиция, тон текста);
  - `references/web-3d-scroll.md` — интерактивные web-презентации:
    3D по чертежам, скролл-режиссура, разрезы, анимация схем;
  - `references/pptx-style.md` — правила PowerPoint/PDF-версий.
- `assets/` — логотипы и фирменные материалы (добавляются по мере передачи).
- `projects/` — материалы и презентации по конкретным проектам.

## Использование

В сессии Claude Code с этим репозиторием попросите презентацию — скилл
`nura-presentation` подключится автоматически. Форматы: интерактивный web
(3D, скролл-анимации, публикация по приватной ссылке) и PowerPoint/PDF.
