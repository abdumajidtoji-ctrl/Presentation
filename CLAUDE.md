# NURA Presentation — паспорт репозитория

Репозиторий системы презентаций NURA GROUP / NURA EPC (высоковольтные
подстанции 10–500 кВ, ЛЭП, СЭС, BESS; форматы поставки, СМР/ПНР, EPC,
EPC+F). Владелец — руководитель отдела продаж NURA ELECTRIC.

## Что есть в репозитории (инвентарь)

### Скиллы (`.claude/skills/`)
**Главный — `nura-presentation`** (наш собственный, приоритетный при любой
просьбе о презентации/визуализации):
- `SKILL.md` — процесс: бриф → сценарий → производство → контроль → сдача;
- `references/design-system.md` — фирменный стиль;
- `references/web-3d-scroll.md` — интерактивный web-формат (3D, скролл);
- `references/pptx-style.md` — правила PowerPoint/PDF.

**Вспомогательные** (сторонние, MIT; используются КАК СПРАВОЧНИКИ внутри
процесса nura-presentation, не вместо него):
- `ui-ux-pro-max` — офлайн-база дизайн-знаний (поиск Python-скриптом,
  без сети): 79 стилей, 192 палитры, 74 пары шрифтов, 119 UX-правил,
  25 типов графиков, 17 GSAP-пресетов. Пример:
  `python3 .claude/skills/ui-ux-pro-max/scripts/search.py "запрос" --domain style|color|typography|chart|ux|landing`
- `slides` + `design-system` (его зависимость) — стратегия слайдов,
  раскладки, копирайтинг-формулы, Chart.js;
- `brand` — создание и поддержание бренд-гайдов;
- `design-dna` — извлечение «дизайн-ДНК» из референсов (скриншоты
  эталонных презентаций/сайтов → JSON-профиль) и ДЕТЕРМИНИРОВАННАЯ
  проверка цветов результата (`scripts/verify.mjs`, ΔE-метрика).

### Локальные библиотеки (не требуют сети!)
`assets/vendor/` — проверены рендером в Chromium этой среды:
- `three/` — Three.js r128: `three.min.js` (UMD), `three.module.js`,
  `OrbitControls.js`. Для 3D-моделей подстанций, ЛЭП, СЭС.
- `gsap/` — GSAP 3.15.0, все 25 плагинов (бесплатны, Standard License):
  ScrollTrigger (скролл-режиссура), DrawSVGPlugin (отрисовка схем),
  SplitText (анимация заголовков), MotionPathPlugin (поток энергии),
  ScrollSmoother, Flip, MorphSVG и др.
- `chartjs/` — Chart.js 4.5.1 (графики; нужен скиллу slides);
- `fonts/` — фирменная типографика с кириллицей (RU/EN/UZ), variable
  woff2: Inter (текст), Manrope (заголовки), Playfair Display (акцент);
  подключать `fonts/fonts.css`;
- `d3/` + `geo/` — D3 7.9 + topojson-client + контуры стран world-atlas
  (слайды «география проектов», трассы ЛЭП; Узбекистан — id "860");
- `icons/lucide/` — иконки Lucide (~1600): `icon-nodes.json` для сборки
  инлайн-SVG, `tags.json` для поиска;
- `three/addons/` — GLTFLoader (3D-модели от проектировщиков),
  UnrealBloomPass + EffectComposer (свечение, постобработка).

Также объявлены в `package.json`; `npm install` ставит их в `node_modules`
(реестр npm в этой среде доступен).

### Материалы
- `assets/` — логотипы и фирменные материалы (пополняется);
- `projects/` — материалы и презентации по конкретным проектам.

## Особенности облачной среды (важно)

- **CDN заблокированы** (cdnjs, jsdelivr — 403 от прокси). Библиотеки
  подключать ТОЛЬКО из `assets/vendor/` или `node_modules`. В публикуемом
  артефакте локальные файлы передавать через параметр `files`; одобренные
  CDN работают у зрителя в браузере, но не из этой среды.
- **npm-реестр доступен** — недостающие пакеты качать через npm.
- **WebGL работает** в Chromium (SwiftShader): 3D-сцены можно рендерить
  и проверять скриншотами через Playwright до сдачи пользователю.

## Правила работы

- Язык общения — русский; презентации и КП по запросу на русском,
  английском, узбекском. Аудитория — в основном государственные
  заказчики: формулировки чёткие и грамотные.
- Перед версткой артефакта загружать скиллы `artifact-design` и `dataviz`
  (для графиков); для 3D/скролла следовать `references/web-3d-scroll.md`.
- Каждую презентацию проверять рендером (скриншоты слайдов/сцен) до сдачи.
- Данные по проектам (цены, объёмы, ТЭП) сохранять в `projects/` —
  информация из одного проекта может пригодиться в другом.
